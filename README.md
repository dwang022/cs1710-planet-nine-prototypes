# Planet Nine — dashboard prototypes

Two coordinated-view prototypes for CS 1710 (Daniel Wang, Gabriel Gonzalez,
Russell Rui Luo). This repo holds only the **built** pages so they can be
served publicly; the source lives in our main project repo.

- **A — cross-filter:** one selection, applied live to both downstream views
- **B — two-sample comparison:** two selections held side by side

Data: 90 extreme trans-Neptunian objects from the JPL Small-Body Database,
cross-checked against the Minor Planet Center.
